# Проверка и отчёт

После изменения выполни повторяемую проверку по риску; для существенной регрессии сохрани тест. Проверяй контракты и документацию, повторяй проверки только после изменения или новой ошибки.

Не упрощай валидацию на границах доверия, обработку ошибок, предотвращение потери данных, безопасность и доступность.

Сохраняй чужие незакоммиченные изменения. Не публикуй, не отправляй сообщения и не выполняй необратимые действия без разрешения. В финале укажи изменённые файлы, фактические команды проверки и неподтверждённые ограничения.
