# Чтение исходников

Сначала прочитай обязательный `AGENTS.md`. Для поиска используй `rg`; большие файлы читай узкими диапазонами. Не загружай весь репозиторий, README, индексы или инструкции без реального вопроса.

При существенной работе узкую ориентацию делегируй. Основная модель читает оригинал адресно для проверки конкретного вывода, diff или спорной гипотезы. Соблюдай форматы и инварианты проекта; справочные материалы не расширяют разрешённый объём.
