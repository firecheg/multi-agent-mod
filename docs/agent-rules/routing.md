# Routing

For substantial engineering work, the coordinator owns analysis and judgment; configured summary workers handle orientation and configured code workers handle implementation and author tests. Small reversible operations stay local with minimal necessary tools.

Choose effort: `low` mechanical, `medium` ordinary engineering, `high` difficult diagnosis or safety, `xhigh` exceptional cross service work. `max` requires explicit permission; unsupported settings are `effective unset`.

Configured role rationale: [`../../memory/brain/agent-routing.md`](../../memory/brain/agent-routing.md).

Use a canary only for delegated or substantial work: report configured model, role, status and real run reference in the first update, on routing changes and in the final. Simple answers have no canary. Allow one initial attempt and one targeted correction after a diagnosed failure, then reassess scope or escalate for a factual reason.
