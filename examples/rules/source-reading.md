# Чтение исходников

Сначала прочитай обязательный `AGENTS.md` текущего проекта. Для поиска используй `rg`; большие файлы читай узкими диапазонами. Не загружай весь репозиторий, README, индексы или связанные инструкции без реального вопроса.

При существенной работе узкую ориентацию и сбор фактов делегируй подходящему исполнителю. Основная модель читает оригинал адресно для проверки конкретного вывода, diff или спорной гипотезы и называет проверяемый вопрос до чтения. Не обходи установленные read gates.

Для bounded research используй `research_batch`: до 6 узких вопросов и до 3 исполнителей одновременно; для одной выжимки — `context_read` на доступном summary worker. При ошибке исполнителя не повторяй платный вызов и не переключайся автоматически на дорогую модель: сообщи ошибку и сузь задачу. Graphify используй для существующего project skill и текущего snapshot; не перестраивай весь индекс без необходимости.

Соблюдай форматы и инварианты проекта. Справочные материалы помогают принять решение, но не расширяют разрешённый объём работы.
